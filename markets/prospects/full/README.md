# Full prospect directories

Each workbook has exactly two sheets, Master Prospects and Decision Makers, and no other columns. Master Prospects lists every accepted directory company. There is no page-count cutoff and no Semrush traffic cutoff. Decision Makers lists only the people already in the matching filtered workbook.

Master Prospects columns, in order: Website Name, Root Domain Link, Semrush Organic Traffic, Website Count, Count Method, Company Phone Numbers, Company Emails, Company LinkedIn, Primary Decision Maker Name, Position. The first five columns come from the accepted directory. A blank website count is stored as Not found. The last five columns are copied from the filtered workbook when that root domain was already researched, and are empty otherwise.

Decision Makers columns, in order: Company Name, Website Link, Contact Name, Position, Phone Numbers, Email, LinkedIn Profile.
